# Documentação por contexto

Um arquivo por contexto (ex.: `identidade.md`, `reservas.md`, `cobranca.md`), mantido pelo dono do contexto e entregue ao cliente no handoff, junto com o material de treinamento na pasta **Entrega** do Drive.

Cada arquivo responde: o que o contexto faz, regras de negócio, onde está o código, como testar e decisões tomadas.
