# Como contribuir

1. Pegue uma tarefa no quadro da sprint no Notion (ex.: `TSK-12`, entregável `B08`).
2. Crie a branch a partir da `develop`: `git checkout -b feature/B08-verificacao-de-conflito develop`.
3. Faça commits pequenos e abra o pull request para a `develop`, preenchendo o modelo.
4. Se o código toca **cobrança, permissão ou IA**, peça também a revisão do dono do contexto.
5. Código gerado por IA é revisado por você antes de pedir revisão. Nenhum dado real de cliente vai para ferramentas de IA.
6. Com CI verde e aprovação, o veterano faz o merge e a tarefa no Notion vai para **Feita**.
